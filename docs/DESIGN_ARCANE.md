### 0.1 레퍼런스에서 읽은 것

- **레퍼런스 1** (로켓을 든 징크스): 어두운 남보라 바탕에 **분홍·하늘색 폭발이 평평한 면**으로 터진다.
  굵은 사선 속도선, **둥글게 덩어리진 연기**를 2~3단 명암으로만 칠했다. 디테일보다 **큰 모양**이 읽힌다.
- **레퍼런스 2** (징크스 초상): **분홍 벽 전체에 하늘색·흰색 분필 낙서**가 겹겹이 깔린다 — 원숭이 얼굴,
  X 표시, 휘갈긴 글자. 낙서는 거칠지만 **획이 굵고 크다**.
- 두 장 모두 인물은 큰 면과 부드러운 명암으로 칠했고, 붓 결은 면 안에서 은은할 뿐 표면을 긁지 않는다.

### 0.2 v0.3에서 바꾼 것

1. **주색은 하늘색과 분홍** (v0.4에서 라임을 더해 셋이 되었다 — 3장). 징크스의 머리색과 낙서색이다. 주황 나트륨등은 뺀다.
2. **자운 배경은 초록.** 화학 연무의 초록이 바탕 분위기를 맡고, 텍스트·상태에는 쓰지 않는다.
3. **날카롭고 세밀한 배경 → 흐리고 단순한 실루엣.** 배경은 큰 면과 2~3단 명암만. 초점이 나간 듯 부드럽게.
4. **자글자글한 흘러내림 → 굵고 몇 안 되는 흘러내림.** 끝이 둥근 굵은 방울 3~5줄까지.
5. **연기는 둥근 덩어리.** 레퍼런스 1처럼 뭉게뭉게한 실루엣을 2~3단 단색으로.

## 1. 디자인 선언

1. **화면은 애니메이션의 한 컷이다.** 큰 면, 굵은 실루엣, 2~3단 명암. 디테일은 인물과 정보에만 쓴다.
2. **공통은 벽에 붙은 포스터, Me는 그 위에 뿌린 분홍 낙서다.**
3. **세 색이 주인공이다.** 하늘색은 지금 고른 것, 라임은 길잡이, 분홍은 나. 초록은 공기, 색이 아니라 분위기다.

### 1.1 현행 기준에서 유지하는 것

- `PRD.md`의 기능 범위, URL 상태, 220ms 전환 목표
- 공통/Me 불변식 — Me 미선택 시 DOM에 없음, 빈 Me 섹션은 영역 예약 없음, **색만으로 구분하지 않음**
- 비대칭 편집 그리드, 강한 한글 디스플레이 타이포그래피, 섹션 번호 `01 / 02 / 03`의 목차 리듬
- 정적 2D Aside 일러스트 (3D·WebGL·회전 금지), Data Dragon `loading` 아트와 `FOCUS_OVERRIDES`
- `DESIGN_BLUEPRINT.md` 12장의 구현 결정 중 시각 표면과 무관한 항목 전부

### 1.2 챔피언 이미지의 한계

챔피언 이미지는 Riot 스플래시·로딩 아트라서 Arcane 그림체가 아니다. 이미지를 다시 그리거나
필터로 바꾸지 않는다. **Arcane 느낌은 이미지를 둘러싼 틀 — 연무, 연기 덩어리, 낙서, 굵은 붓 가장자리 — 가 만든다.**
레퍼런스 이미지(Arcane 장면·포스터)는 방향 확인용이며 사이트에 쓰지 않는다.

## 2. 레퍼런스와 적용 방식

| Arcane에서 알아보는 요소 | 적용 방식 | 하지 않을 것 |
| --- | --- | --- |
| 큰 면과 2~3단 명암 | 배경·패널·장식을 단색 면 2~3단으로 | 세밀한 사실적 배경, 날카로운 디테일 |
| 둥글게 덩어리진 연기 | 페이지 상단과 포스터 뒤에 단색 연기 덩어리 실루엣 | 투명도로 흐릿하게 깐 안개 |
| 분홍·하늘색 폭발과 속도선 | 현재 선택·Me 강조 뒤에 평평한 폭발 모양, 사선 속도선 | 화면 전체에 터지는 폭발 |
| 벽 위 분필 낙서 (레퍼런스 2) | 낙서 SVG 세트를 굵은 획으로 | 레퍼런스 속 특정 낙서를 베끼는 것 |
| 초록 화학 연무 (자운) | 바탕 그림의 공기색 | 초록 텍스트, 초록 상태색 |
| 굵은 페인트 흘러내림 | 선택한 표지·Me 레이블에 끝이 둥근 굵은 방울 3~5줄 | 가늘고 많은 흘러내림, 튄 점 남발 |

**에셋 사용 원칙.** Arcane은 Riot Games의 IP다. 작품의 스틸컷, 포스터, 컨셉아트, 로고,
`ARCANE` 워드마크와 작품명, 징크스의 얼굴과 작품 속 특정 낙서를 사이트에 쓰지 않는다.
낙서 모티프(원숭이 얼굴, X 눈, 구름 등)는 일반적인 낙서 문법으로 새로 그린다.

## 3. 색상 시스템: UNDERCITY

| 토큰 | HEX | 용도 |
| --- | --- | --- |
| Under | `#0B1613` | 기본 배경, 선, 하드 그림자 |
| Sump | `#13241F` | 한 단계 올라온 면, 읽기 패널, 입력창 |
| Fume | `#1E4A35` / `#2F7A4E` | 초록 화학 연무 그림의 두 단 명암. **텍스트·상태에는 쓰지 않는다** |
| Smoke | `#2A2546` / `#3E3766` | 연기 덩어리의 두 단 명암 (레퍼런스 1의 남보라). 장식 전용 |
| Chalk | `#F1EEF4` | 본문, 제목, 밝은 텍스트 |
| Sky | `#4FBDF2` | 현재 선택, 주요 CTA, 활성 탭 |
| Lime | `#D8FF3E` | 길잡이·정보, 낙서 화살표, 마우스를 올린 줄 (현행 기준의 Acid 색) |
| Pink | `#FF4DA6` | `Me` 전용 내용, 개인화 상태, Me 낙서 |
| Me Wash | `#2B1426` | 어두운 패널 위 `Me` 섹션 배경 |
| Smog | `#93A8A0` | 보조 텍스트, 비활성 상태 |
| Rust | `#B0302A` | 읽지 않은 알림 배지. 이 용도 외에는 쓰지 않는다 |

측정한 텍스트 대비 (WCAG 2.x):

| 글자 \ 바탕 | Under | Sump | Me Wash |
| --- | --- | --- | --- |
| Chalk | `16.05` | `14.06` | `14.85` |
| Lime | `16.07` | `14.07` | `14.86` |
| Sky | `8.69` | `7.61` | `8.04` |
| Pink | `6.03` | `5.28` | `5.58` |
| Smog | `7.33` | `6.42` | `6.78` |

- Under on Lime `16.07:1`, Under on Sky `8.69:1`, Under on Pink `6.03:1` — 세 주색 면 위에는 **어두운 글자**를 쓴다
- **Chalk on Lime은 `1.00:1`이다.** 라임 면 위에 흰 글자를 절대 올리지 않는다
- **Chalk on Pink는 `2.66:1`로 실패한다.** 분홍 면 위에 흰 글자를 올리지 않는다
- Chalk on Rust `5.53:1` — 알림 숫자

규칙:

- **주색은 Sky·Lime·Pink 셋이다** (v0.5). Sky는 지금 고른 것, Lime은 길잡이·정보, Pink는 Me.
  한 요소는 한 색만 갖고, 셋을 넓은 면으로 동시에 쓰지 않는다. Lime은 초록 연무(Fume)와 계열이 가까우므로
  연무 위에서는 면이 아니라 테두리·글자로 쓰고 Under 그림자를 붙인다.
- **`공통`은 색을 갖지 않는다.** Chalk 세로선 + `공통` 레이블 + 섹션 번호로 구분한다. 기본 본문이므로
  색이 필요 없고, 그래야 Me의 분홍이 더 분명하게 "덧칠"로 읽힌다.
- **키보드 포커스**는 3px Chalk 윤곽선 + 2px Under 간격(이중 링). 초록이 공기색이 되었으므로
  v0.2의 Chem 포커스는 폐기한다. 선택(Sky 면)과 포커스(흰 이중 링)는 모양으로 구분된다.
- 연무·연기·폭발은 **단색 면 2~3단으로 그린 이미지나 SVG**로 만든다. CSS `linear-gradient`·
  `radial-gradient`로 빛과 안개를 만들지 않는다.
- 발광은 현재 선택(Sky)과 Me 레이블(Pink)에만, 반경 12px 이하.

### 3.1 기존 토큰에서 옮기는 방법

먼저 기존 이름을 새 값의 별칭으로 돌려 화면 전체를 바꿔 보고, 이후 컴포넌트를 옮기며 정리한다.
**읽기 면이 밝은 종이에서 어두운 패널로 뒤집히므로** `--paper` 사용처는 배경과 글자를 함께 확인한다.

| 기존 토큰 | 새 토큰 | 비고 |
| --- | --- | --- |
| `--ink` | `--under` | |
| `--paper` | `--chalk`(글자) / `--sump`(읽기 면) | 쓰임에 따라 둘로 갈린다 |
| `--acid` | `--sky` | 선택의 뜻은 Sky가 잇는다. Acid 색 자체는 `--lime`으로 남아 길잡이를 맡는다 |
| `--gum` | `--pink` / `--me-wash` | |
| `--cobalt` | `--chalk`(공통 표시) / `--sky`(링크) | 공통은 색을 갖지 않는다 |
| `--smoke` | `--smog` | 새 `--smoke-*`는 연기 장식용이라 이름이 겹치지 않게 주의 |
| `--alert` | `--rust` | |

## 4. 타이포그래피

### Display

- **유지: `SB 어그로체 B`.** 두껍고 각진 자형이 굵은 애니메이션 타이틀과 맞고 라이선스 확인이 끝났다.
- 초대형 제목은 **굵은 붓으로 한 번에 칠한 글자**처럼 가장자리만 약간 거칠게 한다(마스크 10% 이하).
  v0.2의 롤러 질감보다 매끈하게 — 레퍼런스의 인상은 거친 표면이 아니라 큰 모양이다.

### 낙서 손글씨 (Me 전용)

- 용도: Me 섹션 레이블, `현재 선택`, 빈 상태 문구처럼 짧은 한두 단어.
- 후보: 굵은 마커·분필 느낌의 한글 손글씨체. 채택 전에 **게임·상업 사용 허용 여부**를 확인한다.
  확인 전에는 Pretendard 굵게 + 기울기 `-4deg`로 대체한다.

### UI 및 본문 / 수치

- `Pretendard Variable`, `IBM Plex Mono` 유지. 어두운 읽기 면에서는 데스크톱 행간 1.7.

## 5. 형태와 질감

- **큰 면 우선.** 배경과 장식은 단색 면 2~3단. 테두리 안쪽의 미세한 긁힘·그레인·벽돌 결은 쓰지 않는다.
- **굵은 붓 가장자리.** 포스터·패널 가장자리는 굵은 붓으로 한 번 칠하다 멈춘 큰 굴곡 몇 개.
  자잘한 톱니 모양은 쓰지 않는다.
- **연기 덩어리.** 둥근 구름 실루엣을 Smoke 두 단으로. 페이지 상단, 포스터 뒤, 빈 상태에.
- **초록 연무 배경.** 자운의 파이프·탑 실루엣을 Fume 두 단의 단순한 면으로, 초점이 나간 듯 부드럽게.
  읽기 패널 뒤에는 두지 않는다.
- **폭발과 속도선.** 선택한 표지 뒤나 Me 레이블 뒤에만 평평한 Sky·Pink 폭발 모양과 굵은 사선 몇 줄.
- **흘러내림.** 끝이 둥근 굵은 방울 3~5줄, 길이는 서로 다르게. 가는 흘러내림과 튄 점은 쓰지 않는다.
- **분필 낙서.** 굵은 획의 SVG 세트 — 원숭이 얼굴, X 눈 웃는 얼굴, 구름, 폭발 별, 동그라미, 화살표,
  하트, 휘갈긴 밑줄. 색은 Sky·Pink·Chalk 단색. 모두 `aria-hidden`, `pointer-events: none`.
- 읽기 패널(Sump) 안에는 질감·연무·낙서를 두지 않는다.

## 6. 화면 Blueprint

### 6.1 글로벌 헤더

- 높이 72px, Under 바탕, 하단 2px Sump 선.
- 현재 메뉴는 Sky 면 위 Under 글자 + 은은한 발광. hover는 Sky 글자만.
- 알림은 종 아이콘 + Rust 배지 + Chalk 숫자.
- **사이트 아이콘**: Under 면 위 굵은 붓 Sky `A`.

### 6.2 라인 선택 화면

> 예정된 구조 변경 반영: 포지션 탭 + 카테고리 포스터 대신 **라인 대표 표지 5장**이 라인 선택을 겸하고,
> 표지를 누르면 그 라인 챔피언이 **티어 내림차순 목록**으로 아래에 펼쳐진다.
> 표지: 탑 문도 박사, 정글 워윅, 미드 빅토르, 원딜 징크스, 서폿 레나타 글라스크 (2026-10-04).
> 다섯 모두 자운 출신이라 초록 자운 배경과 세계관이 맞는다. `PRD.md` 반영은 별도로 한다.

- 상단은 초록 연무 배경 + 연기 덩어리. `누굴 상대해?`는 Chalk 굵은 붓 글자, 물음표에 분홍 분필 동그라미.
- 표지 5장은 한 줄. 선택한 표지는 4열, 나머지는 2열씩. 굵은 붓 가장자리, 둥근 모서리 카드 금지.
- 라인명은 큰 Chalk 글자 + 아래 굵은 붓 밑줄. **선택되지 않은 라인의 밑줄은 모두 Chalk**, 선택된 라인만 Sky.
- 선택한 표지: Sky 테두리 + 발광, 뒤에 평평한 Lime·Pink 폭발 모양(세 주색이 한자리에 모인다), 아래로 굵은 Sky 방울 3~5줄이
  흘러 목록과 이어진다. 선택되지 않은 표지는 연무에 살짝 가라앉는다.
- 원본 표지는 가로(1215×717)라 세로 포스터로 자를 때 표지마다 초점 위치를 지정한다
  — 문도 `50% 25%`, 워윅 `68% 55%`, 빅토르 `47% 20%`, 징크스 `55% 15%`, 레나타 `52% 20%`(실측 전 추정값).
  워윅은 얼굴이 오른쪽 아래에 있어 좁은 포스터에서 잘리기 쉬우니 실제 화면에서 먼저 확인한다.
- 낙서는 화면당 2~3개, 얼굴·라인명·목록을 가리지 않는다.
- **티어 목록**: 표지 아래 Sump 패널. 제목 `미드 · 티어순`. 왼쪽 큰 티어 글자 열(S → A → B …),
  오른쪽 한 줄 한 챔피언. 최상위 티어 글자만 Sky, 나머지는 Chalk.
  - 줄 폭이 넓어 오른쪽이 비지 않게 한다: 목록 최대 폭을 제한하거나 넓은 화면에서 2단으로 흐르게 한다.
    줄에 넣을 추가 정보는 **실제 데이터가 있는 것만** 쓴다.
  - 라인 목록 안의 `MID` 같은 라인 태그는 중복이라 넣지 않는다.

### 6.3 챔피언 화면

#### Aside

- Under 바탕 위 초록 연무 + 연기 덩어리. 일러스트 가장자리를 굵은 붓 마스크로 녹이고 오른쪽에 Sky 림 라이트.
- 초대형 챔피언명은 **Sky** 굵은 붓 글자. 일러스트 뒤에서 일부 가려지는 구도는 유지.
- Q/W/E/R은 2px Under 테두리 + 굵은 붓 프레임, 쿨타임은 Sky 모노.
- 스킬 쪽지는 Sump 면 + 왼쪽 Chalk 세로선.

#### Main

- 읽기 면은 Sump 패널, 질감 없음, 본문 Chalk. 탭은 패널 위에 붙은 굵은 붓 탭, 현재 탭은 Sky 면.
- **공통 섹션**: Chalk 세로선 + `공통` 레이블 + 섹션 번호. 배경 Sump.
- **Me 섹션**: Me Wash 배경 + Pink 세로선 + 분필 손글씨 `Me · 챔피언명` 레이블(뒤에 작은 Pink 폭발 모양) +
  굵은 Pink 방울 2~3줄. 배경·선·레이블 **세 가지 단서**로 구분한다.
- 현재 선택한 Me 섹션: `현재 선택` 텍스트 유지.
- 빌드 추천 행은 Sky 세로선 + `추천 · 최다 선택` Sky 레이블.

### 6.7 홈 — 필트오버 (위의 도시)

홈만 Arcane의 **위쪽 도시 필트오버**로 칠한다. 나머지 화면이 어두운 초록 자운이라 홈에 들어서면
밝은 노을빛 도시가 펼쳐지는 대비가 생긴다. 시각 기준은 `design/blueprints/4-1.png`.

- **팔레트** (`globals.css`): Ivory `#F4ECDD`(패널), Cream `#E9DCC3`(지면), Navy `#14283A`(글자·선·그림자),
  Navy Soft `#4A5D6E`(보조 글자), Gold `#E2B24C`(장식선 전용), Gold Ink `#7A5812`(작은 금빛 레이블).
  Navy on Ivory `12.83:1`, Navy Soft on Ivory `5.80:1`, Gold Ink on Ivory `5.53:1`.
  **Gold는 Ivory 위에서 `1.67:1`이라 글자에 쓰지 않는다.**
- 주색 역할은 사이트와 같다: 하늘색은 현재 메뉴·`전적 찾기`·마우스를 올린 줄. Me(분홍)는 홈에 없다.
- **스카이라인 띠**: 노을빛 필트오버 원경(`public/images/piltover/skyline-*.webp`) 위에 `HOME`
  (상아색 글자 + 남색 외곽선 + 남색 그림자), 상아색 띠 위의 소개 문장, 하늘색 `MATCH ARCHIVE / KR` 티켓.
  아래 경계는 남색 선 + 금 이중선.
- **패널**: 상아 면 + 2px 남색 선 + 6px 남색 하드 그림자. 위 두 귀퉁이에 금 모서리 장식, 소제목 아래 금 이중선,
  즐겨찾기 패널 아래에 금 시계 문양. 장식은 모두 배경 이미지라 접근성 트리에 들어가지 않는다.
- 포커스 링은 밝은 지면에서 보이도록 Navy로 바꾼다 (`.piltover :focus-visible`).
- **v0.1의 함정을 피한다**: 금은 가는 장식선뿐이고, 황동 판·리벳·양피지를 UI 틀로 쓰지 않는다.
- 같은 컴포넌트를 쓰는 `/records`는 자운 화면으로 남는다. 필트오버 규칙은 모두 `.piltover` 아래에만 건다.

## 8. 반응형 규칙

현행 8장을 따르고 다음을 덧붙인다.

- 767px 이하에서는 연무·연기 배경을 단순한 한 장으로, 낙서는 화면당 하나까지.
- 라인 표지 5장은 767px 이하에서 가로 스크롤 한 줄 또는 2+3 배치로 접는다(목업 확인 후 결정).
- 굵은 붓 가장자리 마스크는 가장자리 8px 안쪽에서만 작동해 정보 영역을 자르지 않는다.

## 9. 금지 목록

현행 9장을 유지하되 "빛나는 구체·의미 없는 빛"은 3장 규칙(그린 면만, 출처 있는 빛만)으로 대체한다.

- 세밀하고 날카로운 사실적 배경, 표면 긁힘·그레인 남발
- 가늘고 많은 페인트 흘러내림, 튄 점 남발
- 주황·황동·양피지를 주색으로 세우는 것 (v0.1·v0.2에서 확인한 함정)
- CSS 그라디언트로 만든 빛과 안개, 하늘색→분홍 그라디언트 배경
- 초록을 텍스트·상태색으로 쓰는 것
- 분홍 면 위의 흰 글자 (대비 실패)
- 화면을 뒤덮는 낙서, 얼굴·본문·컨트롤을 가리는 낙서
- 읽기 패널 안의 질감, 연무, 낙서
- Arcane 스틸컷·로고·작품명, 징크스 등 캐릭터 얼굴, 작품 속 특정 낙서 복제
- glassmorphism 패널
